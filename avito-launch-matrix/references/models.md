# Выбор модели и передача работы

Предлагать переключение вручную в интерфейсе ChatGPT. Не утверждать, что модель переключена, и не обещать изменение тарифа/стоимости сессии. Рекомендация не является обязательным условием: если пользователь не переключается, продолжать текущей моделью. Не запрашивать повторное подтверждение после принятого выбора. Не тормозить каждую строку советом о модели.

## Три уместные точки

| Момент | Рабочий класс | Что поручить |
|---|---|---|
| Перед большим корпусом | Экономичная модель + детерминированные инструменты | Извлечение, нормализация, дедупликация, предварительная разметка, подготовка компактных выборок |
| После подготовки фактов, перед стратегией | Сильная аналитическая модель | Проверка Jobs и цитат, противоречия, исполнимость офферов, коммерческие приоритеты, критика выводов |
| После принятия стратегии | Экономичная модель + скрипты | Распределение строк, заполнение по ID, именование, ссылки, техническая сверка; сильную модель возвращать для смысловых конфликтов |

Для генерации изображений использовать предназначенный инструмент: выбор чат-модели не заменяет его. Для финальной смысловой проверки сложного проекта рекомендовать сильную модель; для простой матрицы не навязывать повышение класса.

Не утверждать «большие данные всегда дешевле анализировать слабой моделью». Счёт/дедупликацию выполнять инструментами, чтобы не тратить контекст на весь корпус. Разметку делать порциями с фиксированной схемой и оригинальными ID, проверять выборки сложных/негативных/редких случаев. Сильной модели передавать сводки вместе с доступом к исходным строкам и противоположными примерами, не только выводы дешёвой модели.

## Названия и стоимость

По умолчанию говорить «экономичная», «сильная аналитическая», «текущая». Конкретные названия предлагать только из доступного пользователю списка/проверенных текущих официальных сведений. Не угадывать наличие модели, цену, контекст и лимиты. Для OpenAI применять навык официальной документации и актуальные официальные источники. Различать API-стоимость и условия подписки ChatGPT: переключение в подписке не обязательно означает прямую экономию денег; может менять расход лимитов/скорость. Не утверждать фиксированный множитель экономии.

## Формулировка предложения

«Дальше первичная обработка большого файла. Здесь разумно выбрать экономичную модель, а подсчёты выполнить инструментами. Перед выводами о сегментах и офферах предложу сильную аналитическую модель. Если остаёмся на текущей, продолжу в ней».

Перед важным анализом: «Данные подготовлены. Сейчас нужно проверить Jobs, противоречия и стратегию — на этом этапе рекомендую сильную аналитическую модель. Ниже чекпоинт для продолжения».

## Передача между моделями

Сохранить короткий чекпоинт: проект/цель, текущий этап, ссылки/точные пути источников, факты и конфликты, метод и охват обработки, принятые D/V/N/G, стабильные ID, готовые таблицы/файлы, неизвестное, следующий шаг, разрешённые действия. Не включать пароли/ключи/персональные данные покупателей. После переключения прочитать чекпоинт и необходимые исходники, не начинать бриф заново. Если нет сигнала о переключении, не заявлять, что оно произошло.
